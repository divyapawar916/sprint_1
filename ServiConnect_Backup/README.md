# ServiConnect

ServiConnect is a web-based local services management and booking system.

## Features

- Customer registration and login
- Service provider registration and login
- Browse available services
- Add and manage services
- Book services
- View and manage bookings
- Cancel pending bookings
- Reviews and ratings

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- MySQL
